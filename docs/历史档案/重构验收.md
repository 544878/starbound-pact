## 视觉对照

参考：`refactor-concept.png`。实际界面：`refactor-desktop.png`。已用 view_image 查看两者。

| 检查点 | 实现与决定 |
| --- | --- |
| 配色 | 使用象牙白、深绿、浅金，统一页头、导航与操作区。 |
| 信息密度 | 保留底部五项主导航；概念图左侧模式/成长面板改为顶部模式栏和独立成长页，响应用户“界面臃肿”的要求。 |
| 战场 | 真实 WebGL 地块、材质、灯光、路径与角色精灵；不是把设计截图当游戏。修复宽屏相机裁切与贴图初载更新。 |
| 文字 | 中文主标题、状态条、方向与操作文字均为真实控件。保留原角色姓名；未使用概念图生成的无关姓名/虚构等级和数值。 |
| 角色图像 | 六个角色有全身图集，头像采用等比裁切，修复宽容器拉伸。生成器未输出真正透明 PNG，最终改用统一浅色底；3D 精灵通过材质色键处理背景。 |
| 小窗口 | 压缩场景高度、角色头像及操作区间距；主要操作可滚动访问，底部导航固定。 |
| 响应式 | 390×844、1536×1024 的布局做过检查。IAB 的尺寸覆盖截图存在缩放显示差异，最后回到默认窗口保存 1280×720 截图，因此没有声称做过相同像素尺寸的精确拟合。 |

这轮按概念方向完成了布局、美术及交互核对，但不是概念图逐像素复刻。保留的差异：侧栏结构简化、原游戏角色与真实临时数值替代概念图文本、战场装饰量低于概念图。当前为可玩本地版本，不能声称已达到原作的完整视觉或内容规模。

## 实现边界

- 货币战争为原玩法核心的本地适配，包含前后台/经营/羁绊；原作完整装备、契约、分支节点、赛季规则不在当前实现中。规则来源：[米哈游官方玩法说明](https://sr.mihoyo.com/news/160700)。
- 塔防目前一张地图、五波配置，保留配置扩展入口；没有整套原作关卡/干员系统。
- Three.js 承担 3D 地块、光照、视角、射线选取和精灵场景。角色是立绘精灵，不是可旋转的骨骼模型；材质色键的边缘表现不等同于专门制作的透明贴图。
- 新玩法接入成长规则；早先主线点击战斗与历史数值设计仍保留原规则。本轮没有暗中覆盖既有大型平衡设计。
- 小游戏局内状态在切换页面/刷新时结束；长期养成与成绩保持原本地持久化方式。
- 3D 模块延迟加载，约 533 KB 压缩前构建体积，Vite 的 500 KB 提示仍存在；不影响运行，未为消除提示而隐藏警告。
