# 星阵 3D 战斗样板

入口：主页 → 进入作战 → 星阵试炼 · 3D 回合战 → 开始战斗。也可从“更多 → 编队”进入。

## 已实现

- 独立实时 3D 场景：月下石台、金色刻线、悬浮建筑、五名关节角色与机械星骸 Boss。舞台模型由原创几何构成，不是角色图片贴片。
- 五人职责：抗伤、治疗、主攻、协攻、专辅；阵线根据成员存活状态显示。沿用已选角色及成长属性，试炼将成员调谐到战前选定体系。
- 八阵法：逆道、红尘、色欲、极炎、梦境、记忆、终末、时序。沿用原有伤害通道函数、42%基础联动和45%上限，以及各体系触发条件。试炼数值为单独战斗尺度，不替代既有五人阵法平衡模拟器或完整角色适配配置。
- 普攻恢复战技点；战技消耗1点；终结技消耗100能量。守护、群体治疗、专辅强化、独立敌方回合、每三轮重击、死亡跳过和胜败结算。
- camera-controls 平滑镜头、攻击推进、角色关节/发梢动作、命中粒子和光环、克制泛光。伤害在演出44%处提交，动画期间锁定命令。
- 自动、1/2倍速、全阵视角、简洁演出、音效开关、Q/E/R键盘操作、战报、战前阵法选择、奖励领取及再次挑战。

## 模型资产

`public/assets/models/` 中的六个 GLB 是当前游戏几何的独立导出：

- guardian.glb：抗伤角色；healer.glb：治疗角色。
- striker.glb：主攻角色；mage.glb：协攻角色；specialist.glb：专辅角色。
- astral-guardian.glb：星骸守阵者。

人物包含 Idle、Attack 节点动画，Boss 包含 Idle。使用原创关节网格建模，未使用商业游戏提取模型。它们是风格化样板模型，不是精细面部绑定、布料物理或完整动作捕捉资产。

重建导出：`node scripts/export-astral-models.mjs`（Node 22.13+）。模型与舞台实现共享 `astralModels.ts`。

## 验证与边界

- 77项规则测试通过：包括八体系完整轮转、死亡失联、治疗不复活、致死后不反伤、资源边界、专辅增益时序、掉落合并与旧玩法回归。
- 浏览器实测：编队进入、真实WebGL绘制、普攻/战技、自动倍速、简洁演出、六回合胜利（5人存活、10500实际伤害）、奖励返回主页。
- 桌面与390×844竖屏检查：顶部标题、Boss状态、行动序列、阵图、五人生命、技能按钮。修复旧页面64px顶部占位和底部裁切。
- 模型质量仍是原创风格化样板，未宣称达到《星穹铁道》角色建模精度。战斗机制是当前项目的可玩改造，不是该商业游戏的完整复刻。
- 尚未在实际安卓/iOS硬件上测帧率；WebGL不可用时显示说明并保留战斗按钮。刷新页面重开当前战斗，养成与已领取奖励保留。
