# 八大核心体系数值设计 v0.1

本轮交付独立数值配置、伤害计算器与自动验证。不创建角色，不修改既有角色、属性或存档；现有点击战斗仍使用原有规则，尚未接入本计算器。以下面板代表同阶段的体系测试模板，不是角色面板，也不是装备成长终值。

## 1. 统一口径

- 每回合体系行动一次，然后 Boss 行动一次。时序不增加行动次数。
- 基准 Boss：生命 24000，攻击 900，防御 500；无抗性，每回合一次攻击。
- 防御乘区：`1000 / (1000 + 防御)`。500 防御减伤 33.33%，1000 减伤 50%，防御上限 9000，对应最高减伤 90%。攻击线性增长，防御边际收益递减。
- 基础伤害 B：`攻击 × 防御乘区 × (1 + 有效易伤)`。
- 有效易伤：`min(50%, 面板易伤 × (1 − Boss易伤抗性))`。负抗性代表效果放大。
- 直接伤害期望：`B × [1 + 有效暴击率 × (爆伤倍率 − 1)] × 阶段倍率 × (1 − 直接抗性)`。
- 追击伤害：`B × 追击系数 × 回响层数系数 × (1 − 追击抗性)`。
- DoT：`B × DoT系数 × min(回合/3, 1) × (1 − DoT抗性)`。每次行动续上一层，最多三层，每层为面板系数的三分之一；本版假设连续行动，回合末结算一次，不设计停手、驱散或持续时间事件。
- 暴击只作用于直接伤害，暴击率最高 80%，爆伤为总倍率，最高 250%（即暴击时 2.5 倍）。追击、DoT各自系数最高 80%。
- 所有伤害抗性限制在 −50% 至 75%，防止负伤害或完全免疫。不同伤害通道只使用对应抗性。
- 吸血：`直接与追击实际扣血量 × 吸血率 × (1 − 治疗压制)`，受缺失生命及每回合最大生命 8% 双重限制。吸血率最高 25%。过量击杀不产生额外吸血。
- 反伤：`自身实际受到的扣血量 × 反伤率 × (1 − Boss反伤抗性)`。反伤率最高 50%，不再经过防御、易伤、暴击；致命攻击不触发反伤。
- 结算顺序：直接→追击→DoT→吸血→存活 Boss 攻击→存活体系反伤。Boss 已死亡则不反击。
- 追击、DoT、反伤均不触发新的攻击事件；DoT和反伤不吸血。易伤只计算一次。
- 内部保留小数，显示时取整。计算器使用暴击期望值，因此不代表随机实战的伤害波动。

输入保护：攻击限制 0～100000，生命 1～1000000，非法非有限输入回退到下限。上述限制是计算器保护边界，不是推荐成长区间；跨等级数值仍需重新校准。

| 体系 | 核心机制与优势 | 必须保留的短板 |
|---|---|---|
| 逆道 | 45%反伤、高防御；敌方攻击越强，非致命反击收益越高 | 主动伤害较低；反伤抗性、低攻击目标克制；堆防御会降低反伤基数 |
| 红尘 | 高生命、均衡伤害与吸血；稳定承伤 | 无特殊爆发乘区，输出预算低于输出专精体系 |
| 色欲 | 高易伤、高吸血，以主动输出维持生命 | 初始生命低；禁疗与爆发克制；易伤已经接近上限 |
| 极炎 | 三轮满层DoT；持续输出绕开暴击压制与直接伤害抗性 | 首轮弱、续航弱；DoT抗性直接削弱核心 |
| 梦境 | 高暴击和爆伤，直接攻击期望高 | 生命防御低、没有反伤；暴击压制后明显衰减 |
| 记忆 | 追击回响：第1/2/3轮达到满系数的1/3、2/3、全部 | 需要启动，追击不能暴击；追击抗性克制 |
| 终末 | 体系行动开始时Boss生命≤30%，本次直接伤害×1.25 | 不强化追击或DoT；前期伤害普通，生存和吸血较弱 |
| 时序 | 第3、6、9…轮直接伤害×1.45 | 不增加行动与DoT次数，普通轮输出低；短战可能错过窗口 |

终末阈值实际按体系行动开始时的 Boss 生命判定，当次直接伤害打入30%不会追溯加成。

## 3. 八种 Boss 规则

均为无角色身份的机制配置，共用基准面板，仅覆盖下表字段。抗性按伤害通道生效，不做体系名字的硬克制。

| 对应体系 / Boss | 特殊数值 | 主要考验及应对 |
|---|---|---|
| 逆道·折锋法则 | 直接抗性30%，DoT抗性−15%；爆发攻击节奏 | 压制直接爆发，极炎DoT相对占优 |
| 红尘·厚土法则 | 防御700，易伤抗性−50%，反伤抗性−20% | 高防御耐久；色欲易伤达到50%上限，逆道反伤不再过防御 |
| 色欲·枯荣法则 | 攻击980，治疗压制70%，反伤抗性−35% | 压制吸血续航；高原始生命、防御与反伤更可靠 |
| 极炎·焚界法则 | DoT抗性50%，直接抗性−10%；递增攻击 | 极炎受损，直接爆发收益提高 |
| 梦境·无相法则 | 暴击率扣除40个百分点，追击抗性−20% | 梦境受损，记忆追击较有利 |
| 记忆·断响法则 | 追击抗性50%，DoT抗性−15% | 记忆受损，极炎较有利 |
| 终末·残照法则 | 直接抗性−12%，DoT抗性15%；爆发攻击节奏 | 鼓励直接爆发，同时考验扛住峰值攻击 |
| 时序·迟滞法则 | 追击抗性25%，易伤抗性50%，反伤抗性−40%；递增攻击 | 压制追击和易伤收益，逆道反伤较有利 |

爆发节奏：每三轮攻击倍率依次0.5、0.5、2.0，三轮平均为1.0。递增节奏：第1轮0.7，每轮增加0.1，最高1.5；长战比基准更危险。

中性12轮最高/最低输出比约1.108，低于设定的1.15警戒线。全部存活；红尘剩余生命最高，逆道以部分主动输出换生存。不同Boss的最高输出体系会变化，未出现一个体系在所有Boss都输出第一。

本结果仅证明这一阶段固定面板的期望值稳定，不代表完整游戏已平衡。12轮内基准Boss尚未进入30%生命，因此终末斩杀优势另有阈值单测，不能由本表评价完整击杀强度。后续应在引入队伍、角色、技能或装备后追加击杀回合、随机暴击分布、治疗队友和跨等级测试。

本版易伤是单体系的有效值，未实现多人叠加。后续队伍实现应按同名取最大、不同来源相加后统一限制50%，不能重复创建易伤乘区。暂不分配成长点、装备词条或额外攻击乘区。

自动验证覆盖64种对局最长100轮的资源边界、伤害通道隔离、暴击与反伤上限、过量扣血、死亡停止反击、阶段倍率和中性输出差距。模拟器默认12轮，调用上限1000轮，未决返回timeout，不能作为胜利。
