## 01 · 露弥（lumi）

5星 · 专辅 · 时序 · 风元素
**核心：把溢出充能送给下一位行动者，不直接拉全队行动条。**
90级裸装：攻击457，生命11660，防御605，速度106；基础暴击5%，额外暴伤50%。
参考成装：攻击1,057，生命24,948，防御1,060.88，速度128.5；暴击5%，额外暴伤50%，充能效率168%，专精90。
### 能量条
备用能量（双段）：上限120，最低大招费用80，初始24；普攻基础+18，战技基础+24。
额外来源：自身超过80的部分进入40容量备用段；队友溢出能量时收集其数值的25%，每自然回合最多12；收集不能再次触发收集。
释放方式：大招扣80，不清空备用段。
### C0完整技能
**普攻：** 80%攻击单体。
**战技：** 消耗1战技点；指定一人，其下次自然行动后获得10%大招门槛的本源充能，最多每自然回合一次；露弥自身获得24能量。
**大招：** 全队获得2次“满格不浪费”：溢出充能的50%送给行动条上下一名队友，每次最多对方门槛的10%；另造成120%攻击群伤。
**被动与边界：** 充能转赠不复制任何命座或武器回能；受赠者无需时序标签。
### C1—C6
| 节点 | 独立效果 |
|---|---|
| C1 | 开场备用段额外存10能量。 |
| C2 | 战技目标满能时，充能保留至其下次大招后，最多保存一次。 |
| C3 | 大招群伤120%→170%，不扩大回能比例。 |
| C4 | 转赠目标可由玩家指定，不再强制下一人。 |
| C5 | 战技附带清除目标1个减速效果。 |
| C6 | 每次大招可保存两名不同角色各一次溢出；同一角色仍只收一次。 |
### 专武
**回风的诗章**，5星，90级R1：攻击360、生命1200、防御0；副属性充能效率+20%。
R1被动：发生一次真实的充能转赠后，接收者下次伤害提高12%【R】，持续至一次主动攻击结束；不能叠加，跨体系有效。
R2/R3/R4/R5仅将文本中标【R】的伤害/治疗/盾量系数乘1.10/1.20/1.30/1.40；次数、资源、持续时间、层数和行动提前不变。无【R】项的武器改为对应角色主缩放属性+2%/4%/6%/8%，属于同一属性加算池。
跨角色适配：同星级面板完整保留；能完成被动要求的行为即可触发，不做姓名或原生体系扣分。
