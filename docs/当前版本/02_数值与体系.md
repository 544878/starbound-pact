# 星契 V2：八体系与全角色重构案

版本：2026-09-11 · 设计与独立规则验证稿。原始基线为《全角色与敌人数值现状记录.md》。本稿保留51名角色、原角色ID、原星级、原元素、原体系归属与专武物品名；不声称已修改原游戏。联动角色在本文中的技能是为“星契”重新设计的技能，不是原作现行机制介绍。

## 阅读约定与边界

“完全不能重复”在本方案中落实为：八体系的主要资源来源、决策问题、兑现方式不同；每名角色有独立核心循环；不能把同一三动作模板换名就算新角色。普攻回战技点、护盾结算、减防上限等底层规则必须共用，否则系统无法一致计算。通用治疗、防护和辅助故意可以跨队，不视为重复。

原体系名保留用于存档、剧情与检索；战斗说明显示直白副标题：逆道·盾反、红尘·接力、色欲·换血、极炎·燃烧、梦境·识破、记忆·回放、终末·攻坚、时序·调度。技能界面只使用“举盾、接力、回补、点火、拆招、回放、破绽、蓄力”等易懂词。已有角色与物品的正式名字不强行改掉。

“1主5次”按上下文解释为每件前六魂拥有1个主词条、5个副词条；副词条数量与强化次数分开。本稿规定5条初始副词条，再有5次强化，共10份副词条基础量。不是“1主词条加5次随机强化但只有2副词条”。

所有五星0+1指C0、90级、90级专武R1，不是专武R5。四星C6的对标武器为可锻造四星R5、相同魂词条预算；五星彩色外观和后3魂不额外免费抬面板。四星C6≈五星0+1是同岗位、同资源、指定标准场景中的验收目标，容差±5%，不是每一场战斗中逐项完全相等的数学断言。五星的适配场景、目标数切换、应急能力应更完整；不能同时要求四星“所有情况下严格更弱”又“所有情况下完全相等”。

## 一、先统一引擎，而不是在旧模板上继续叠加

### 1.1 队伍、时间与行动

保留五人队，但取消固定站位强行改技能与跨体系攻击折扣。角色带什么技能就用什么技能；站在哪个格子不把治疗变为输出、不把输出变为护阵。每队通常是两名输出、一名辅助、一名防护、一名治疗，也允许双辅单生存、单C双生存等；界面提示风险，不禁止编队。

引入真正生效的速度与行动时间AV：自然行动间隔=10000/速度。速度100的角色每100AV行动一次；100AV称一个“时间轮”，不是固定“五人都动过一轮”。关卡计时按AV，禁止把阵法的“第三轮”与某角色第三次攻击混用。

每个自然行动选择普攻或战技。普攻通常+1战技点，战技通常-1；开场4点，上限7。额外返还、接力奖励等每100AV全队合计最多+2点，满点返还不储存，只有灯禾明确可以存。强化普攻默认仍为普攻，但角色文本明确写“不产点”时不产点。不能因命中五个敌人获得五次普攻回点。

大招在两个事件之间插入，不取代自然行动；不生成新的自然行动，不产生战技点。一个角色两次大招之间必须完成一次自己的自然行动，且大招起始时间至少相隔10AV。持续型/预约型角色还必须满足其形态结束或预约结算条件。大招派生包不得再次以“大招施放”触发整套被动。

行动提前按目标当前剩余行动距离计算，但同一自然行动间隔内累计提前不超过该角色基础间隔的30%，最后距离至少1AV。行动后退同理最多30%。时珩的预约攻击和晷宁的定时风刃是独立时间事件，不是新增自然回合。所有技能持续时间必须明确写AV、施法者自然回合或目标自然回合，三者不互换。

### 1.2 事件结算顺序

一次根行动按以下顺序执行：合法性与费用校验→实际扣费→基础面板与目标读取→主动伤害/主动治疗/施盾→记录真实损失/吸收/治疗→死亡判定→附着与反应→合法被动事件→资源收益→状态到期与日志。需要伤前救命的效果另挂“致命前”事件，不能用普通伤后治疗伪装复活。

每个事件有root_id、event_id、source_actor、target、parent_id、tags、depth。tag至少包括NORMAL_ACTION、ULTIMATE_ROOT、FOLLOW_UP、DOT_NATURAL、DOT_EARLY、REPLAY、SUMMON、REACTION、SHIELD_ABSORB、HP_COST、SKILL_HEAL、PASSIVE_HEAL、ENERGY_TRANSFER。角色没明说“队友/全队”时，触发者默认是本人；没明说自然结算以外触发时，不把提前结算当自然结算。

主动事件最多向下产生2层派生事件；额外给每个root 32个事件的运行时安全阀。正常允许的链会预先在数据中声明，触发上限是角色文本和规则的一部分；32个事件是异常报警防崩溃，不是用来掩盖无限循环的平衡办法。

回放、召唤、反应、武器附加和魂的附加包，默认不能再创建回放记录、增加接力人数、返还战技点、充能或复制自己。只有角色文本明确放行的单个回能钩子有效，仍受自然回合次数上限。伤害型追加可触发伤害统计与死亡，但击杀不再次生成无限转移。

### 1.3 统一属性与伤害

删除显示面板÷250的第二套尺度：界面、日志、配置、测试均使用同一套属性点。防御、攻击、生命不能有的乘250有的不乘。等级成长g(L)=0.40+0.60×(L-1)/89，L取1至90；裸装基础攻击/生命/防御乘g。武器各自按等级成长，不再读取“持有者的武器预算”来冒充装备自身属性。

攻击A=(角色基础攻击+武器攻击)×(1+攻击百分比)+魂等平面攻击。生命H与防御F同式。速度v=角色基础速度+速度平值，再乘明确的速度百分比修正。暴击伤害统一指“额外暴伤”：50%表示暴击1.5倍，不再把总倍率与额外倍率混写。

主动伤害与普通追击：

    基础包 B = a×攻击 + b×防御 + c×最大生命 + 固定值
    期望暴击系数 C = 1 + clamp(暴击率,0,1)×额外暴击伤害
    敌方有效防御 F_e = max(0, 基础防御×(1-min(减防,0.50)))
    防御系数 G = 1000 / (1000 + F_e)
    有效抗性 r = clamp(该元素抗性-该元素减抗, -0.40, 0.70)
    最终期望伤害 D = B×(1+同池伤害加成)×C×G×(1-r)×(1+易伤)

全伤、元素伤、同种通道增伤进入一个加算池，不偷偷变成三个独立乘区。易伤同池上限30%。普通破韧窗口统一提供20%易伤，与其他易伤同池，所以已有20%易伤时破韧只补到上限30%，不是再乘1.2。攻击/防御/生命百分比同类加算。说明中的“+18%伤害”默认是同池伤害，不是最终乘1.18；【R】只表示武器精炼可放大该数值。

主动攻击和一般追击可暴击；燃烧、中毒、反应、盾反仓库附加量不暴击。技能明确有特殊结算时优先按其文字。持续伤害与直接反应伤害使用专精系数：

    P(M) = 1 + 1.6M/(M+400)，M为专精，M≥0。
    自身燃烧/中毒每次伤害 = 对应角色属性系数×P(M)×增伤×G×抗性×易伤。
    非攻击系数型反应的90级基数 R0 = 1500；低等级R0乘g(L)²。

回放采用施放者当前面板代入“允许复制的基础技能系数”，而非拿最终伤害再乘一遍暴击与减防。瑟琳只复制攻击缩放战技，不复制生命/防御缩放、额外资源、召唤或大招；这是明确的资源边界，不是临时修补。

“单体”只命中1人；“扩散”未另写时主目标100%标称系数、相邻最多2人各50%；“群体”对所有存活敌人使用标称系数。召唤物与替身不增加我方人数，不增加群攻治疗分母。

默认主动命中的基础削韧为普攻10、战技20、大招30，技能明确写出的数值替代默认值；不造成伤害的治疗/护盾技能不自动削韧。多段主包共享这份预算，不能每刀都获得完整削韧。普通追击、持续伤害和回放默认不削韧，明确标出的例外按文本。命中所列弱点时，本人的基础削韧乘1.25，额外固定削韧不重复放大。

韧性归零时打断可中断蓄力，并把敌方下一自然行动后退10AV；同一Boss每100AV最多因此后退一次。破韧窗口40AV，结束恢复最大韧性的75%；不恢复生命、不清除未到期负面。Boss的生命护盾、韧性条、阶段机关是三种不同东西。光暗破障只能驱散普通可驱散增益，不能跳过剧情阶段机关。

普通可抵抗负面的最终施加概率=基础概率×(1-效果抵抗)，上限100%；没有命中特别说明的普通负面基础概率100%。Boss永久关卡规则、已经发生的费用与伤害不能用效果抵抗抵消。

### 1.4 护盾、治疗、生命费用

治疗量=(生命系数×施法者最大生命+攻击系数×施法者攻击+固定值)×(1+治疗加成)×(1-治疗压制)。有效治疗=min(标称治疗,目标实际缺失生命)。溢出治疗单独记账，不能同时算有效治疗。默认反应治疗、魂治疗、武器治疗和被动回补不触发“技能治疗回能”；需要例外必须指明并给次数上限。

护盾量=(防御/生命/攻击系数+固定值)×(1+护盾加成)。同一来源重复施盾只保留较大剩余值并按文本刷新时长，不无上限叠层；不同来源可叠，总剩余盾不得超过目标最大生命50%。优先消耗即将到期的层；磐舟的内外层优先级单独定义。

敌方攻击先算目标防御、抗性和减伤，再扣盾，再扣生命。总减伤上限65%。只把该护盾真正吸收的数值记给其提供者，不能把其他人提供的盾记到玄照仓库。

主动生命费用不受护盾、防御、减伤影响；只按实付数量记账。每笔费用生成唯一编号，后来有效治疗最多回补该编号的剩余损失；一笔失血不能被两次登记回补。提高最大生命不会凭空产生失血或治疗。

盾转移、盾自然到期、主动拆盾与分层合并都不是敌方击破护盾。间桐樱和岳衡的延期伤害只允许一层延期，不能互相套娃；延期期间上限、到期、治疗偿付和死亡处理都独立留痕。

### 1.5 盾反的完整操作例

玄照为队友提供5000盾，敌人预告重击，经该队友防御、抗性与减伤后需要造成4000伤害。玄照此前已给该人架盾，因此盾吸收4000，生命不损失；仓库增加4000×35%=1400，而不是要求掉血4000才能反击。最大生命40000时仓库上限4800。

若同一次群攻打中5人，普通C0只记录指定的两名架盾者，且所有来源共享仓库上限。大招基础反击=340%玄照防御，仓库部分=1400；两部分分开结算。基础部分可按正常主动技能计算暴击/增伤；仓库部分不再暴击、不吃增伤和易伤，只乘敌方防御与抗性。它仍不是无视防御的真实伤害。

对面不出手时，玄照能靠普攻/战技积累盾能；空仓大招得到100%防御后备伤害。盾反的长处是把防守行动转为可择时的收益，不是强迫玩家站着挨打、故意不治疗。

## 二、能量条必须改变决策

主能量、技能内部标记与敌方状态分开。例如绯月有血量/回补双条；阿尔托莉雅的守护条与剑光格分开；吉尔伽美什是分档弹仓；炎煌是消耗式热量；时珩是可选择付费加速的预约。不是把100蓝条改成100红条。

每名角色的容量、费用、开场量、普攻/战技收益、额外来源、支付后余量都在逐角色表中列明。开场量不套用“所有人50能量”；各角色设计时就有自己的启动成本。

充能效率仅作用于表中普攻/战技的数值充能与明确标记为可加成的数值事件。离散格子以隐藏小数进度累计：例如每次获得1颗宝石、充能效率120%，则加1.2颗进度，显示1颗+20%进度；没有相应行为，不能凭充能效率无中生有地得到一份记录、一种颜色或一次格挡事实。

通辅“本源充能”默认给大招最低门槛的指定比例，仍不得超过该角色每自然回合15%门槛的外部充能上限；没有明确数量的被动转赠不享受接收者充能效率。记录、颜色、剑光、目标标记等条件不随数值充能产生。炎煌强化期间禁止外部回热，守岸人领域未结束不能重开，弗洛洛指令未用完不能再次开大；这些是各自差异，不是BUG。

一次转赠最多走一跳。A把能量送B，B不能以“收到能量”为理由送C再送A。外部充能满格时默认丢弃；只有露弥和凛明确的保存许可可以暂存，且每个许可只用一次。

### 能量计算示例

诺克缇娅初始1段，战技+1；不依赖敌人残血时，连续两次战技即可达到3段。期间若队伍成功击破一次，则第一自然行动后的合法插入点即可开大，但下一次大招仍需完成自己的自然行动、时间间隔≥10AV且重新攒到3段。

吉尔伽美什初始2发，可以早开2发得到80%+2×90%=260%攻击；等到6发则80%+6×90%+100%=720%攻击。前者灵活、后者单次与每弹收益更高，且两者都占一次大招施放机会。6发不是把两发大招免费连放三次。

炎煌100热量开大，入大不先扣40；40只是启动门槛。每次自然行动开始耗25，无回热时最多3次强化行动被硬性结束，因此最多实际耗75，结束后的25保留；剩余低于25则提前退出。这条避免用充能队无限维持最强形态。

## 三、15组元素关系

保留火、水、森、风、光、暗，不为增加组合再塞一堆新元素。每个主动根行动对同一敌人默认最多附着1次；多段技能要单独给附着预算，不能每刀都触发一次。每个根行动最多3次反应，按玩家主目标优先；反应伤害不再施加元素，不由反应创造反应。

敌方最多保留两种不同元素，每种最多2单位、到期100AV；新元素优先和最早仍有效的不同元素消耗各1单位反应，第三种不能无上限共存。风本身不留下持续附着，只消耗已有一种元素。反应归触发者所有，专精读取触发者；未说明的反应伤害均为元素伤害，受目标防御和对应抗性，不暴击。

| 风+森 | 播种 | 将一个将到期的回春种子或药印剩余一次使用机会转给合法新目标；没有此类状态则治疗最低者0.45R0×P(M)。搬运不复制次数。 |
| 风+光 | 导光 | 下一名不同队友主动主伤害包忽略目标5个百分点元素抗性，仅一次，40AV过期；仍受抗性下限-40%限制。 |
| 风+暗 | 藏身 | 为当前被点名者解除一次可转移的仇恨锁定；Boss不可转移时改为该次点名伤害降低12%，不改变群攻。 |

施加顺序不改变同一组合效果，降低记忆负担；只有触发者和其专精不同。要追求更复杂的强弱附着，可以留作后续版本，不在第一次重构里同时引入。

## 四、魂：前六魂1主5副，后3魂承担有限功能

### 4.1 主词条与强化

魂强化0—20级，主词条值=m20×(0.20+0.04×等级)。0级即满值20%，每级线性增加；+4/+8/+12/+16/+20各强化一条副词条。五条副词条在获得时就全部显示，杜绝强化完才发现第五条是什么。

| 槽 | 可选主词条，以下为+20满值 |
|---|---|
| 1 | 固定生命+1800 |
| 2 | 固定攻击+240 |
| 3 | 固定防御+180 |
| 4 | 攻击28%、生命28%、防御35%、暴击18%、暴伤36%、治疗18%、护盾18% |
| 5 | 元素伤22%、追击伤22%、持续伤22%、生命28%、防御35%、专精96 |
| 6 | 攻击28%、生命28%、防御35%、速度16、充能24%、专精96 |

| 副词条 | 每一份基础量 | 备注 |
|---|---:|---|
| 攻击百分比 | 3% | 不与本件相同主词条重复 |
| 生命百分比 | 3% | 同上 |
| 防御百分比 | 3.8% | 同上 |
| 暴击率 | 1.8个百分点 | 最终硬上限100%，溢出默认无收益 |
| 额外暴伤 | 3.6个百分点 | 和总暴击倍率区分 |
| 速度 | 1.5 | 平值，不是1.5% |
| 充能效率 | 2.4个百分点 | 只作用合法来源 |
| 专精 | 10 | 代入P(M) |
| 治疗加成 | 1.8个百分点 | 和治疗压制分开 |
| 护盾加成 | 1.8个百分点 | 不让盾转移反复吃加成 |
| 削韧加成 | 3个百分点 | 对本人的基础削韧乘1+加成，固定额外削韧不再放大 |
| 效果抵抗 | 3个百分点 | 对普通可抵抗负面，不抵抗关卡永久规则；总上限60% |

每件魂五条不同副词条；不能和同件主词条同名，固定生命/攻击/防御与百分比副词条不算同名。五条初始各1份，五次强化每次再加1份，所以单件始终共10份，六件共60份；不是每条强化五次导致总量翻五倍。

初始副词条从合法池等概率无放回抽5条。每次强化基础为五条各20%；玩家可选一条定向，连续两次未命中该条则第三次必定命中，成功后重置计数，切换定向也重置。由此一个定向命中的等待时间期望=1+0.8+0.8²=2.44次，而非原本5次。合成目标是减少垃圾词条，不增加理论满分上限：可消耗60魂片固定主词条，额外40魂片固定两条初始副词条；其余3条仍从合法池抽，不保证满强化分配。

换件返还90%强化经验；副词条重置退还100%强化经验、不给定向道具返还；基础道具不出售战斗属性上限。后期允许120魂片重置五次强化分配，保留原五条副词条。具体材料产出速率属于经济系统后续实测项，本稿不伪装已经平衡了整套付费与掉落。

### 4.2 六个槽位的专精技能

每槽二选一专精技能，等级1—5；总计最多六个小技能，不能把12个全装。技能随魂强化+12解锁，升级仅用普通素材，不要求重复角色。专精技能等级与面板专精M是两件事。

| 槽 | 选择一 | 选择二 | 1—5级数值 |

这些小技能提供选择，不能替代人物核心机制；可玩测试时应分别跑“无专精技能”和“全满专精技能”，防止装备把缺陷遮住。所有附加包均带EQUIPMENT标签，不复制自己。

### 4.3 后3魂

7号防守魂：选开场100AV内效果抵抗+20个百分点，或本场第一次生命低于35%时获得自身最大生命8%护盾；后一项在本次伤害及存活判定后触发，不能当作复活。8号支援魂：选跨波保留不超过10%门槛本源能量，或开场给全队一次共同可用的1战技点，二者不兼得；跨波保留不能叠到原容量之外。9号攻击魂：选本场第一次破韧时本人下一主动主包+8%同池增伤，或第一次对新一波敌人主动命中削韧+10。每槽每场/每波上限按此执行，不出现“全伤永久+20%”的隐藏三件套。

普通与专属后3魂使用相同数值上限，专属只改变动作表现和方便预设；旧普通环75%预算、专属35%无视防御和吸血文案不迁移为免费效果。开放条件为对应等级与任务，不把基础技能修复绑在抽卡上。

### 4.4 养成的定量例

一件魂若初始为攻击3%、暴击1.8%、暴伤3.6%、速度1.5、充能2.4%，五次强化落在攻击1次、暴击1次、暴伤2次、充能1次，则最终：攻击6%、暴击3.6%、暴伤10.8%、速度1.5、充能4.8%。基础份数=2+2+3+1+2=10。

专精0/100/200/400时P(M)=1/1.32/1.533333/1.8；后续收益递减，不用无限线性堆专精。M=400再加100，P由1.8到1.888889，持续伤害相对提升约4.94%，不是“专精+100所以伤害+100%”。

## 五、武器与星级关系

51件专武都有自己的攻击/生命/防御、一个副属性、独立被动与次数边界，逐角色给出。武器属性由物品本身决定，不因换一个持有人就偷偷变成对方专武预算。没有“异主自动只生效85%”或“跨体系扣35%攻击”。达到行为条件就能触发，达不到只能获得基础属性；适配由机制产生，不靠隐藏姓名检查。

R1保留完整功能；R2—R5只将明确标【R】的伤害/治疗/盾系数依次乘1.10/1.20/1.30/1.40，所有资源、次数、持续时间、行动提前均不变。未标【R】的武器改给持有者主要缩放属性2/4/6/8%的同池属性加成。不能用R5把一次反击变五次、再多触发十套回能。

替代武器提供六类通用锻造方案：输出“普通长刃”攻击450/暴击15%；持续“练习法器”攻击450/专精80；防护“守卫装备”攻击250/防御233/生命1000/生命16.67%；治疗“医用器具”攻击267/生命1500/治疗10%；支援“旅途手册”攻击300/生命1000/充能16.67%。R1效果依次为本人主动增伤6%、本人持续增伤6%、本人盾量6%、本人治疗6%、首次大招后返还门槛3%；R5对应10%、10%、10%、10%、3%且支援追加生命4%。资源收益不因精炼线性爆炸。第六类为生命输出“生命长刃”：攻击200/生命2667/生命23.33%，R1给本人生命缩放主动伤害6%同池增伤，R5为10%；不能要求绯月用纯攻击武器当作公平替代基准。

五星0+1相对同角色四星通用R5的岗位贡献，目标提升12%—18%；不能承诺每把当前都已达到此范围，要用完整角色循环测量。武器释放独特操作选项时，纯数字增幅应取区间较低端。

### 5.1 命座目标与必须测量的量

四星C0的同岗位标准贡献目标是五星0+1的60%—72%；C6在自己的专长场景达到95%—105%，跨场景中位数宜略低。五星C0就有完整循环；C1/C2提升启动、灵活性或一种明确分支，C3/C5可提高关键系数，C4增加容错，C6拓宽一种打法。不能把“不会空转、能按技能”锁在C2。

输出看固定AV总伤害、首轮伤害、单体与3目标、资源支出和输出方差；治疗看有效治疗、救下致命风险的次数、耗点与等待时间；护盾看有效吸收、覆盖与实际免伤，不能拿生成后没用掉的盾冒充贡献；辅助看替换前后全队净提升与队伍耗点。不同角色的价值不能压缩成一个人为拍出来的“战力100”。

建议配对验收：艾尔登/磐舟与玄照比单体重击保护；春蘅/雨织/岁安与米菈/樱/守岸人分别比持续、攻击取药、救急；汐辞与瑟琳比反应供给而不是假装两者都能复制技能；司命与露弥比实际队伍输出改善，不直接比回能次数。若岗位本来不同，只能比较完成相同战斗目标的代价，不强造“完美一一替代”。

## 六、八队基础操作与资源核验

所有默认队均有五名不同角色；可替换角色都不触发跨体系面板惩罚。推荐是演示完整机制，不等于已验证所有关卡最优。按每人三次自然行动合计15次的基础循环：主C“战技、战技、普攻”；副C“战技、普攻、战技”；辅助“战技、普攻、普攻”；防护“战技、普攻、普攻”；治疗“普攻、战技、普攻”。7次战技消耗7，8次普攻产生8，净+1；开场4点应按实际速度与动作顺序审查中途是否欠费。大招不耗战技点也不产战技点。

盾反队先由玄照架盾，砺川准备削韧许可，朔衡保留大招到预告重击后；霜砚不是故意把厚盾拆掉才能工作，普攻/战技可自启动。面对不攻击敌人把一个防护位换为通辅，不硬吃缺点。

接力队先让灯禾或艾尔登做保护动作，米菈只在有缺血时主动治疗，星璃/尘歌再攻击接棒；满血时以护盾代替假治疗，不为了“有效治疗”故意受伤。南絮分支进一步提高普攻价值。

换血队先上优诺护盾再让绯月支付自身生命费用；护盾挡敌人伤害但不挡生命费用。米菈回补已经发生的真实损失，绛音在安全线内提供选择。大招不要求把自己压到1血。

燃烧队先施加不同来源燃烧，再根据敌人将死与否决定自然结算、焰笙提前消耗或曜烬满档引爆。烬羽负责剩余次数转移；没有次数的燃烧不能被“引爆”算一遍空伤害。

识破队先看镜弦揭示的动作类型，镜玄拆招，梦珀处理可转移点名，梦璃打对应窗口；守岸人让关键爆发的随机暴击波动降低，但不平白增加期望值。Boss免疫改目标时使用已写好的减伤后备效果。

回放队先由沧澜低潮战技生成可录制主动包，瑟琳锁定不同目标形状的记录；忆澜把一次校准留给真正的回放，避免浪费在普通追击；樱给延后伤害缓冲。溯白替代时改为保存敌方防守参数，不再照抄技能或接力配方。

攻坚队由终祈标记高威胁敌人，诺克缇娅围绕蓄力和破韧累积终结段；坎特雷拉选择毒伤继续结算还是换治疗。队伍有启动手段，不必等Boss生命降到30%后才开始战斗。

调度队先确定下一次破韧和敌方重击的时间点，再预约时珩重击；露弥保存溢出，卫宫选单体或群攻投影，阿尔托莉雅决定继续守护还是拔剑。凛、司命、晷宁的替换改变调度手段，不只是改成另一个“每三轮+45%”。


## 七、能量界面与自动战斗

每个角色只常驻显示一条主资源、最多一组必要副标记。容量、门槛和施放模式写数字，不只靠颜色：例如“85/120；普通80；满档120”，或“4/6发；可选2/4发”；绯月分别写“可用血量70/100”和“已回补40/100”。鼠标悬停或手机长按能看到下一次普攻/战技的预期收益，以及本自然回合剩余外部充能上限。

主条数值足够但缺录像、颜色配方、召唤指令未用完或预约未结束时，按钮显示具体原因，不用含糊的“条件不足”。数值主条与副条件不会互相冒充。盾反日志至少显示“谁的盾吸收多少—允许记录多少—仓库上限—本次释放多少”。

自动战斗默认保留最低1战技点给生存，并遵守各角色安全线。有预告重击先检查护盾/打断再用输出；优先真实有效治疗，不在满血时刷奶；不在目标即将死于已排队伤害时继续投入满档弹药；不会为了保持低血而关闭必要治疗。技能次数与优先级是待接入引擎的策略规则，不把本文当作已经完成的AI。

# 八体系编队总表

机制分类不自动给予整队隐形增伤；实际收益来自下列角色自己的技能。

## 逆道 · 盾反

看预告→架盾→吸收敌方攻击→存入有上限仓库→选择反击时机

默认五人队：朔衡 / 霜砚 / 砺川 / 玄照 / 米菈。

可替换：艾尔登替玄照：单点保护；磐舟替玄照：分层盾；岳衡替霜砚：降低输出换抗重击。

独立资源：架盾成功次数，不因生命损失直接增长。

局限：敌人不攻击或无预告时收益降低，但普攻/战技仍可自启动。

## 红尘 · 接力

不同角色完成不同主动动作→传递下次普攻/协击许可→合奏兑现

默认五人队：星璃 / 尘歌 / 灯禾 / 艾尔登 / 米菈。

可替换：南絮替尘歌：强化普攻支线；心月狐替灯禾：两人协约支线；春蘅替米菈：便宜持续奶。

独立资源：不同角色/动作贡献名单，不记录追击和大招衍生包。

局限：多人受控或倒下时接力损失；无需五人全活才能使用基础技能。

## 色欲 · 换血

主动支付真实生命→记录损失→有效回补→消费已经补回的资源

默认五人队：绯月 / 绯棠 / 绛音 / 优诺 / 米菈。

可替换：春蘅替米菈：平滑回补；间桐樱替优诺：分期支线；坎特雷拉替绯棠：毒疗支线。

独立资源：有唯一编号的实际失血和回补账，不奖励被敌人击伤。

局限：压治疗关需先解机制；低血安全线禁止主动送死。

## 极炎 · 燃烧

附着火种→按时间/敌方行动自然结算→选择延长或提前消耗剩余次数

默认五人队：曜烬 / 烬羽 / 焰笙 / 赤垒 / 雨织。

可替换：炎煌替曜烬：持续开大支线；凯尔替曜烬：低成本单体引火；汐辞替烬羽：元素反应支线。

独立资源：各来源燃烧的剩余结算次数；提前结算必须扣次数。

局限：短波战会损失未结算伤害；焰笙/凯尔提供提前兑现。

## 梦境 · 识破

读取可见敌方意图→拆招或诱导→集中攻击该动作暴露的窗口

默认五人队：镜玄 / 梦璃 / 镜弦 / 梦珀 / 守岸人。

可替换：眠鸢替梦璃：伏击支线；米菈替守岸人：直疗保障；玄照替梦珀：识破盾反混合。

独立资源：一次具体敌方动作的意图与识破标记，不读隐藏随机结果。

局限：无预告目标少识破奖励，但基础技能与后备效果照常工作。

## 记忆 · 回放

主动技能生成可复制记录→锁定内容→支付资源→消耗记录回放

默认五人队：沧澜 / 瑟琳 / 忆澜 / 玄照 / 间桐樱。

可替换：溯白替沧澜：书页合成支线；汐辞替瑟琳：元素尾音支线；梦珀替玄照：处理点名。

独立资源：不可复制的记录ID和可复制基础技能包；回放不产生新记录。

局限：不能复制大招、敌方技能、生命/防御缩放或最终伤害，爆发上限明确。

## 终末 · 攻坚

集中削韧/打断→累积破绽→抓窗口放大招→收尾或转移有限溢出

默认五人队：诺克缇娅 / 坎特雷拉 / 终祈 / 优诺 / 守岸人。

可替换：弗洛洛替诺克缇娅：召唤压制支线；暮刃替坎特雷拉：多目标收尾；心月狐替终祈：协约跨队。

独立资源：由主动技能和破韧生成的破绽；不只在残血时才开始工作。

局限：转火成本较高，但标记死亡转移、打断免疫后备条款避免完全失效。

## 时序 · 调度

预约攻击/安排顺序→管理有限提前与延后→让爆发落在同一窗口

默认五人队：时珩 / 卫宫 / 露弥 / 阿尔托莉雅 / 间桐樱。

可替换：吉尔伽美什替时珩：弹仓支线；远坂凛替露弥：配方支援；司命替露弥、晷宁替卫宫：低成本改期。

独立资源：绝对AV、预约事件和有限弹仓；额外事件不生新自然回合。

局限：安排错误会错过窗口；预约可取消/重选，不能无成本无限修改。
