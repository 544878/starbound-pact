## 苍穹暴风领主 · 风暴领主
动作循环：1.10攻击单体，先点名 → 0.70攻击群体，点名前告知 → 预告25AV后1.60攻击群体重击。
核心机制：风墙有3点稳定度。预告重击时，我方成功架盾承受一次伤害削1点；任意两名不同角色主动战技命中也削1点，每根行动最多一次。破墙后Boss本次重击伤害减半，后续40AV额外削韧+10。
解法一：读重击预告后架盾，再利用反击打破韧性。
解法二：不用盾反：让不同角色战技连击拆风墙，或先破韧打断重击。
阶段变化：生命首次低于60%时获得2点新风墙并召唤1名风向斥候；低于25%只将下一次重击改为两个可见点名，不直接永久翻倍攻击。
## 断响海皇 · 海皇
动作循环：0.90攻击单体并标潮印 → 0.65攻击群体 → 预告20AV后潮印目标1.50攻击、其他人0.50攻击。
核心机制：潮印记录最近一次我方主动主包的元素，Boss只对该元素临时额外20%抗性、持续60AV，不压所有追击。两个不同元素主动命中，或三名不同角色主动命中，任一可解除。召唤泡盾术士最多1名。
解法一：换元素完成两次命中解除潮印。
解法二：纯元素队用三名不同角色主动命中，或先击破泡盾术士。
阶段变化：50%生命时两人挂潮印，仍提前显示目标；移除任一潮印令另一个剩余时间减半。
## 焚界龙骸 · 火龙
动作循环：1.05攻击单体 → 0.75攻击群体并热量+1 → 若热量≥3，预告30AV后1.55攻击群体；否则1.10单体。
核心机制：开场热量1，上限3。两次我方主动战技击中可选胸口结晶可降温1；水反应一次也能降温1；三次不同燃烧来源的自然结算也能降温1。每100AV最多降温2，最低0。热量不是持续伤害抗性。
解法一：水元素反应降温，留技能打断吐息。
解法二：燃烧队保留三种火源让结晶过载，或不用元素直接战技打结晶。
阶段变化：生命低于50%时胸口结晶恢复，但热量不凭空升满；下一次吐息会烧毁仍活着的一只爆藤，爆藤反噬仍受上限约束。
## 枯荣司祭 · 祭司
动作循环：0.80攻击群体 → 1.15攻击单体并附1次35%攻击中毒 → 预告25AV后1.20攻击群体；完成净化条件则降为0.60。
核心机制：场上两座可攻击药罐各6000生命，存在时治疗压制30%，不压护盾。打破一罐压制降至15%，两罐全破解除；或在60AV内完成3次不同角色的主动伤害/治疗混合动作，直接解一层。反应/被动治疗不能刷动作。
解法一：集中打掉药罐，恢复治疗。
解法二：护盾或延期伤害先抗压，再以不同角色的主动动作解除；无奶队也能靠三个主动攻击动作完成较慢路线（需5次而非3次）。
阶段变化：首次40%生命时恢复一只6000生命药罐，不重置已完成的动作计数；全场治疗压制最高30%。
## 无相天君 · 镜面首领
动作循环：展示点名或群攻二选一意图，动作1.10单体/0.70群体 → 建立一个12000生命镜影 → 预告25AV后1.45攻击，形式取自上一条已公开意图。
核心机制：真身的预告有实线边框，镜影为虚线；攻击镜影不导致全队暴击被永久扣。打破镜影可让真身暴露40AV，或不理镜影对真身完成两次正确拆招同样暴露。暴露用统一20%易伤窗口，不再乘额外倍率。
解法一：看实线预告，拆招或替身承接点名。
解法二：群攻清镜影，或普通队先击破真身韧性直接开窗口。
阶段变化：生命低于50%时最多两只镜影，镜影总存活上限2；单次群攻对真身只造成一次主包伤害，不因镜影复制多倍。
## 残照刑天 · 双刃巨人
动作循环：1.25攻击单体 → 0.65攻击群体并开始蓄力 → 预告30AV后对点名目标2.00攻击。
核心机制：蓄力有两枚锁扣，各需20固定削韧。任意主动战技可削对应锁扣；两个不同角色命中各削10。打断、破锁或成功架盾承受预告重击均使其露出2点破绽，持续60AV。生命高于50%也能触发。
解法一：集中削韧打断蓄力，给终末队终结段。
解法二：预先护盾/替身/伤害缓冲接住重击，然后反击；不要求某一具体盾角色。
阶段变化：低于35%生命时改为两个1.10攻击的点名，仍逐个预告；不会对低血目标执行无视护盾的必杀。
## 迟滞命轮 · 时钟机关
动作循环：0.90攻击单体 → 给下一次重击启动30AV可见倒计时 → 倒计时结束1.35攻击群体；已停表则0.60攻击群体。
核心机制：倒计时中两次不同角色主动战技命中可停表；一次准确预约重击命中可停表；或破韧直接停表。机关最多让一人的下一次自然行动后退10%，每100AV一次，不偷走整回合。
解法一：用时序预约配合可见倒计时。
解法二：普通队保留两人战技，或直接削韧；无需高速才有行动机会。
阶段变化：50%生命时倒计时30→25AV，预告仍完整；每次停表后的下次倒计时额外+5AV帮助连续处理，上限35。
## 覆天古主 · 古代守卫
动作循环：1.20攻击单体 → 0.75攻击群体并给两名近卫各一次保护许可 → 预告30AV后1.50攻击群体压地。
核心机制：两名近卫各使Boss承伤降低15%，最多30%；击杀近卫可拆。也可完成攻击/治疗/护盾三类主动动作拆一份保护；纯输出队用5次不同角色主动攻击拆一份。没治疗/盾角色不会无解。
解法一：先清近卫，降低防守。
解法二：接力队用多类主动动作拆保护，或者纯输出队通过五人主动攻击拆；对单体Boss仍可用减防攻坚。
阶段变化：低于50%不复活近卫；开始“守住/反攻”公开姿态切换：守住时攻击减15%、防御+15%；反攻时攻击+10%、防御-15%。无隐藏全伤反震。

## 深塔18层
每层提供三选一祝福：本层特色、应急保护、稳住循环。只能选一项；连战的一整层只选一次，不在每波重复领开场奖励。旧版该层的隐形伤害倍数全部停用，不能新旧叠加。
应急保护：本层第一次敌方重击前，全队各获得自身生命8%盾；只一次。稳住循环：每100AV首次由不同三人依次完成主动行动后回1战技点，仍受全队额外点上限。
