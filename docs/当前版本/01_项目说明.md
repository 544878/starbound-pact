## 游戏定位

《星契纪元 · 万界同行》是本地单机玄幻角色养成游戏。玩家招募同行者、培养技能与装备、组织五人队伍，在主线与深塔中结合敌方机制选择行动。角色身份、星级、职责、体系和元素是不同维度，图鉴分别索引。

八体系分别为逆道（盾反）、红尘（接力）、色欲（换血）、极炎（燃烧）、梦境（识破）、记忆（回放）、终末（攻坚）和时序（调度）。体系用于表达操作策略；V2设计允许跨体系组合，不依靠固定站位把角色技能替换成通用职责动作。

## 当前内容与运行边界

| 模块 | 当前入口与口径 |
| --- | --- |
| 角色与装备 | V2设计包含51名角色，每人有独立技能文本、能量规则、六个命座节点、专武与魂配置；角色目录和个人拥有列表分开 |
| 主线 | 八章32关，剧情与奖励由主线数据维护，战斗使用V2入口 |
| 深塔 | 18层；敌人与关卡阅读版列出基础遭遇映射 |
| 主战斗 | `App.tsx`引用`BattleV2Screen.tsx`，连接V2行动时间、技能、资源、元素与结算模块 |
| 养成与资源 | 角色、武器、技能、魂与突破通过现有状态系统维护；资源副本遭遇由V2目录按副本配置生成 |
| 祈愿与商城 | 角色、装备获取与库存使用本地状态；商城订单是模拟交易 |
| 活动与家园 | 保留货币战争、保卫战、同设备对决与家园；活动仍有独立结算模块，应分别核对 |
| 存档 | 格式版本10；当前浏览器存储和迁移由`gameState.ts`维护 |
| Unity与3D | 独立移植及样板资源，不作为当前网页V2一致性证据 |

“51个基础遭遇”包括自由战、主线和深塔配置；资源副本通过代码动态映射，不能把51当作所有可运行战斗的总数。角色全部具有设计数据，也不能直接据此断言每项特殊机制均已完整验收。

## 开发与维护

在项目根目录执行`npm install`、`npm run dev`启动。构建用`npm run build`，自动检查用`npm test`。调整设计前先确定修改属于角色、全局数值、敌人或外围系统，再更新对应源文件和验证。设计目标、运行行为和历史验收分别记录，避免引用旧测例数量说明当前质量。
