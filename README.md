# 星契纪元 · 万界同行

本地单机玄幻角色养成游戏，以五人编队、技能搭配、主线探索与深塔挑战为核心。网页端使用 React、TypeScript 和 Vite；进度保存在当前浏览器。商城为本地模拟交易。

本文于2026-09-11按当前工作区重写。当前V2设计覆盖51名角色、51件专武、8位Boss和51个基础遭遇；主战斗入口已接入V2。设计覆盖数量不等于完整实战验收结论。

## 本地启动

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build`生成`dist/`，`npm run preview`预览构建结果，`npm test`运行自动检查。

## 版本口径

- 最新规则设计源是[星契V2完整重构设计](星契V2_完整重构设计.md)，[HTML版](星契V2_完整重构设计.html)用于浏览。两者也是数据导出的输入，保留原路径。
- V2配置为`src/data/v2/design.json`，行为实现位于`src/systems/v2/`。实际行为以代码及对应测试为准。
- 当前存档格式版本为10，迁移逻辑位于`src/state/gameState.ts`。个人存档不等于全目录配置。
- Unity是独立移植目录；部分活动仍沿用原结算模块，不能套用V2主战斗的全部规则。
- 旧数值规划和改动前快照退出当前阅读入口，集中在`docs/历史档案/`。
