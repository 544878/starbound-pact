# 星契纪元 · 万界同行网页端

React + TypeScript + Vite 的本地单机玄幻游戏。本次实现以网页为运行入口，不依赖 Unity。游戏进度保存在当前浏览器；无需账号或付费接口。

## 启动

```sh
npm install
npm run dev
```

打开终端给出的本地地址。生产构建为 `npm run build`，构建结果在 `dist/`；验证使用 `npm test`。

## 当前可玩内容

- **13 位同行者**：保留原有七人，新增玄照、沧澜、炎煌、镜玄、司命、岳衡。神、半神、帝、神使、大尊和主角团作为身份，四星/五星作为稀有度。新角色可在图鉴用金币定向结契，也进入对应祈愿池。
- **13 套独立角色设定图**：GPT 内置绘图生成，每套包含正面、侧面、背面、萌版。图鉴可切换视角、放大和下载原图；主页、角色头像、召唤、家园、主线战斗已接入。原图为 1774×887 四栏设定图，视角是二维绘图，不是可旋转三维模型。
- **九重魂环**：前六环随等级开启，后三环可装备通用环或角色专魂。魂环属性、回复、斩杀、减伤、三击回响、治疗增幅、急速、穿防、吸血参与实际战斗；每枚专魂额外提供 3% 伤害系数。专魂可定向炼制，或按角色/环位独立祈愿（8%，30 次硬保底）。
- **13 把本命专武**：获取、锻造、装备、强化、精炼和存档均已接通。正确持有者获得攻击 +18%、伤害系数 +8%，另有流派被动：减伤、追击、灼烧、治疗、暴击、斩杀、回能或全员存活增伤。异主只获得基础攻击。
- **八章 32 关主线**：以凡人反抗祭城神谕为开端，展开海民记忆、帝王责任、医者平等、自由意志、权力问责、改写天书和万界重建。每章有四场剧情战斗和两种章节选择。最新选择在后续战斗中提供星璃直接伤害 +12% 或全阵承伤 −8%。目前采用文字剧情与立绘演出，无配音影片。
- **八位首领**：苍穹暴风领主、断响海皇、焚界龙骸、枯荣司祭、无相天君、残照刑天、迟滞命轮、覆天古主。各有独立画面与法则；直接/追击/持续抗性、暴击压制、禁疗、逐轮增幅、破盾与半血阶段均进入结算。
- **五人阵法与八层深塔**：真实编队、三组可保存预设、自动职责分配、手动/自动、倍速、音效、简洁演出和战报。深塔每层祝福生效；扫荡已通关层消耗体力。
- **祈愿、任务与补给**：常驻/限定/兵装分别保底；新获取入库，重复提升命座/精炼，记录真实历史。每日/每周/每月任务按北京时间更新，并随消耗、胜利、祈愿、养成与领取进度推进。商店用游戏货币实际兑换体力、金币与材料。家园收益按时间计算并防止重复收取。
- **原有活动保留**：货币战争、星光守卫战、同设备双人对决继续可玩。货币战争加入完整角色池与已装备武器数值。塔防保留花庭地图与原有精灵演出。

## 存档与结算

存档版本为 6，沿用原存储键自动迁移，保留已拥有角色、养成、专武专魂、任务领取、阵容预设与章节选择。正在进行的战斗刷新后回到编队；已消耗体力不会返还。主线与深塔仅在胜利后结算，首通奖励只发一次，已经领取的同一场战斗不能再次领取。

默认存档继承原项目的试玩起始资源、七名角色和少量已通关进度。新增内容不是全部赠送；可通过主线、任务、兑换、祈愿和定向结契取得。满命/满精炼重复获取仍写入历史，目前不额外兑换其他货币。

103 项自动检查通过，覆盖既有玩法、新角色与装备存档、非法/重复结算拦截、任务跨日、八个首领可通关、八种专武被动与深塔祝福。实际浏览器已验证主线读剧情、编队、自动战斗胜利、领奖、刷新恢复，以及招募、锻造、装备、祈愿历史和窄屏布局。

当前是本地网页可玩版本，数值仍需更广泛的长期游玩平衡。原有 30 位四星设计模板保留为设计资料，不计入本次已实装的 13 位角色；其独立美术与完整角色实现尚未制作。原三维场景实验文件保留，但主线已采用精绘萌版二维战场。
